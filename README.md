# Taller Relaciones Muchos a Muchos - Laravel

Proyecto desarrollado en Laravel para practicar relaciones muchos a muchos entre personas e intereses.

## Funcionalidades

- Registro de usuarios con autenticación.
- Panel principal con estadísticas.
- Creación de intereses.
- Creación de personas.
- Asociación de personas con intereses.
- Gestión básica de usuarios.
